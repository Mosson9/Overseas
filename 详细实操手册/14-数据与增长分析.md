# 14 · 数据与增长分析（实操手册）

> 脑图有分析散点，但缺自己产品的指标体系。本篇给你**北极星、漏斗、工具栈、A/B、看板**的落地方案。

---

## 一、最佳实践

### 1.1 用北极星统领，不盯虚荣指标 ✅
- 建议北极星：**付费用户的有效互动时长** 或 **D7 留存的付费用户数**（兼顾留存与变现），而非单纯 DAU。

### 1.2 按结构看数，不被均值骗 ✅
- 一切指标按**国家/渠道/素材/公会/主播**分群下钻，避免均值掩盖结构问题。

### 1.3 实验文化，A/B 一切 ✅
- 素材、首充档位、新手引导、礼物面板、PK 节奏全部可实验。

---

## 二、指标体系

### 2.1 健康度漏斗
```
安装 → 注册 → 首次互动 → 次留 → 首充 → 复充 → 大 R
```
每一环看转化率，找最大流失断点优先优化。

### 2.2 关键指标分层

| 层 | 指标 |
|---|---|
| 获客 | CPM/CTR/CVR/CPI/注册成本 |
| 留存 | 次留/7留/30留/首日有效互动率 |
| 变现 | 付费率/ARPPU/LTV |
| 决策 | D0/D7/D30 ROAS、回本周期 |
| 供给 | 开播主播数/有效房间数/黄金档房间覆盖 |

## 四、A/B 测试 SOP
1. **一次一变量**，定义清晰假设与成功指标。
2. **样本量与周期**充足（避免过早下结论）。
3. **分群看结果**（不同国家可能相反）。
4. **胜出固化、失败回滚**，沉淀实验结论库。

---

## 五、看板搭建建议
- **增长看板**：分国家/渠道/素材的 CPI、留存、ROAS。
- **变现看板**：付费率、ARPPU、LTV、大 R 分布、拒付率。
- **供给看板**：主播开播/留存/流水、公会贡献、黄金档房间覆盖。
- **内容安全看板**：违规拦截量、举报处置时效。

---

## 六、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 盯 DAU 等虚荣指标 | 增长假象、不赚钱 | 北极星=留存付费复合指标 |
| 只看均值 | 掩盖结构问题 | 分群下钻 |
| A/B 多变量同改 | 无法归因 | 一次一变量 |
| 样本不足早下结论 | 误判 | 足够样本与周期 |
| 数据孤岛 | 无法下钻 | 数据中台打通（见 11 篇） |
| 无实验沉淀 | 重复踩坑 | 建实验结论库 |
