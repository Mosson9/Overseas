# 09 · 支付与资金合规（实操手册）

> ⚠️ 高风险区。本篇讲清**IAP 合规边界、支付渠道选型、拒付风控、以及最敏感的合规回款架构**。在回款上省的钱，可能是将来最贵的法律账单。

---

## 一、最重要的边界：什么必须走商店内购（IAP）

📊 **铁律**：
- **数字内容/虚拟货币（金币、钻石、礼物、会员）在 iOS/Android App 内购买，必须走 Apple IAP / Google Play Billing**，平台抽成 15-30%。绕过=下架+可能封号。
- **第三方支付（Stripe/PayPal/本地渠道）只能用于**：实物、线下服务，或 **App 外的 Web 充值页**（用户在浏览器充值，而非 App 内跳转）。

🔧 **行业打法与红线**：
- 普遍做法：引导用户"到官网/H5 充值更划算"，把大额充值引到 Web 用第三方支付省抽成。
- ⚠️ **在 App 内放跳转外部支付的链接/按钮本身违反平台政策**（除非符合 Apple/Google 在特定地区/诉讼下放开的外链规则，如美国部分判例、欧盟 DMA）。**做之前必须确认目标国当前政策。**
- 🔧 **引导动作要在 App 外/客服私域完成**（脑图"客服引导 3 方支付"正确，但不能在 App 内跳转）。

| 维度 | 关注点 |

## 三、拒付（Chargeback）风控 SOP
- 📊 拒付率超阈值（Visa/MC 约 0.9-1%）会被罚款甚至封号冻结资金；社交打赏是拒付高发区。
- 🔧 防控：**3DS 验证 + 设备指纹风控 + 首充限额 + 异常大额人工审核 + 保留充值消费凭证 + 接 Ethoca/Verifi 拒付预警**。
- 🔧 监控：建拒付率看板，按渠道/国家/用户分群预警；高拒付用户拉黑。

## 四、⚠️ 资金回流：合规架构（重大法律提示）

脑图"自费/U"几乎确定指 **USDT 等加密货币对敲**，"回收"问"如何回大陆、降汇费"。

**必须明确**：用 **USDT 对敲、地下钱庄、虚拟账户拆分**回流资金，**可能触犯外汇管理、非法经营、洗钱**，是这个行业**老板被抓的最高频原因**，不是"汇费优化"。

### 🔧 合规资金架构（应当采用）
1. **离岸主体收款**：香港/新加坡运营主体用 Adyen/Stripe/PayerMax 等**持牌渠道**收单，资金先沉淀境外。
2. **合规回流路径**：
   - **ODI 备案**下的资本项目回流；
   - **跨境服务贸易**：境内公司与境外主体签**真实**技术/服务协议，按公允价格结算（需真实业务实质+完税）。
3. **持牌换汇/汇款**：香港 **MSO 牌照**机构、Wise、持牌跨境支付机构，**而非地下钱庄/USDT 对敲**。
4. **一案一议**：跨境资金、转让定价、税务居民身份必须由专业税务/法律顾问设计。

> **赚钱靠运营，回款靠合规架构。**

## 五、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| App 内绕 IAP/跳外部支付 | 下架 | 数字内容走 IAP，引导在 App 外 |
| 只接卡不接本地方式 | 新兴市场转化腰斩 | 必接本地钱包+代扣 |
| 拒付率超标 | 罚款+冻结+封号 | 3DS+限额+预警+凭证 |
| 单一渠道 | 冻结即断流 | 多渠道分散+备用 |
| 订阅选了不支持续费的渠道 | 无法自动续订 | 选支持 recurring 的 |
| USDT/对敲/地下钱庄回款 | **刑事风险** | 离岸主体+ODI/服务贸易+持牌通道 |
| 无税务架构 | VAT/GST 欠缴、补税罚款 | MoR 渠道或专业税务架构 |

## 六、验收标准

- [ ] 数字内容走 IAP，App 内无外部支付入口（或确认目标国政策允许）。
- [ ] 主战场本地支付方式已接入。
- [ ] 拒付风控（3DS/限额/预警/凭证）上线，拒付率看板可用。
- [ ] 资金回流走合规架构，已咨询税务/法律顾问。
- [ ] 多渠道分散，有备用渠道防冻结。
