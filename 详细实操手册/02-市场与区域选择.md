# 02 · 市场与区域选择（实操手册）

> 选对区域 = 用对的产品打对的人。本篇给你**区域决策树 + 各区落地参数 + 进入顺序 SOP**。

---

## 一、区域决策树（先回答三个问题）

```
1. 我的变现靠礼物打赏吗？
   ├─ 是 → 首选 MENA（海湾六国）；次选土耳其、东南亚(印尼)
   └─ 否（订阅/广告）→ 欧美（订阅）/ 印度·非洲（广告+规模）

2. 我现在最缺的是"验证模型"还是"赚钱"？
   ├─ 验证 → 先去 CPI 便宜的拉美/北非/印尼跑通漏斗
   └─ 赚钱 → 直接上海湾高 ARPU 市场收割

3. 我有没有该区域的本地人/本地公会资源？
   ├─ 有 → 该区域优先
   └─ 没有 → 先选文化门槛低的（拉美/东南亚），MENA 必须先补本地资源
```

---

## 二、各区域落地参数卡

### 2.1 MENA（中东北非）— 礼物社交的"提款机"
- **核心国**：沙特、UAE、科威特、卡塔尔（最壕）；埃及（量大但 ARPU 低，适合铺量）。
- **内容偏好**：**语音 > 视频**；社交炫耀/送礼文化极重；荣誉/排行榜驱动打赏。
- **黄金窗口**：**斋月（Ramadan）夜间活跃和消费暴增**，是一年最大营收窗口，提前 1-2 月备战。
- **支付**：mada（占沙特卡支付 93%）、STC Pay（1000 万用户）、Apple Pay、运营商代扣；沙特电子支付占零售 85%。
- **红线**：宗教、政治、两性内容是法律级红线，审核尺度全球最严。
- **本地化必做**：阿拉伯语母语审校 + 完整 RTL；女性形象着装保守；本地公会与本地审核员。

### 2.2 土耳其 — MENA 旁的"视频特区"
- 文化偏欧美，**偏好视频**（与海湾的语音偏好不同）。
- 建议**独立运营**，不要和阿语区共用一套内容尺度和素材。

### 2.3 欧美 — 订阅/婚恋友好，打赏接受度低
- **付费意识强但 CPI 最贵**；秀场打赏文化弱于亚非。
- 更适合**订阅型（婚恋/交友/AI 陪伴）**。
- 合规最重（GDPR/CCPA/未成年人），内容与数据合规要前置。

### 2.4 印度 — 高 DAU、低 ARPPU
- 人口红利大、传播性强，但**打赏 ARPPU 低**，靠**规模 + 广告 + UPI 轻付费**。
- UPI 是刚需（2025/12 月 216 亿笔交易）。
- ⚠️ 别把印度当收割场，当**增长与品牌曝光场**。

### 2.5 东南亚 — 印尼桥头堡
- 社交电商/娱乐 2025 $47.58B → 2030 $186.5B（CAGR 31.4%）。
- 印尼占区域 39%、智能机渗透 89%；越南增速最快、65% 年轻人口。
- 钱包碎片化：印尼 GoPay/OVO/DANA/ShopeePay（合占 ~85%）、菲律宾 GCash（8600 万）、越南 Momo、泰国 TrueMoney。

### 2.6 拉美 — 最佳"试验田"
- 巴西、墨西哥**量大、CPI 便宜、视频接受度高**。
- EBANX 是本地支付首选。
- 🔧 用来低成本跑通素材/漏斗/留存，再平移到海湾收割。

### 2.7 非洲 — 超轻量+广告变现
- Transsion 生态（TECNO/Infinix/itel 预装）是关键渠道；移动优先、低端机、弱网。

## 三、进入顺序 SOP（资源有限团队）

1. **试验田先行（1-2 周）**：在拉美/北非/印尼，用便宜量验证产品漏斗（注册→首次互动→次留→首充）。
2. **主战场收割（验证通过后）**：把跑通的素材/玩法/档位平移到 **MENA 海湾**，配齐本地公会、阿语审核、本地支付。
3. **辅战场扩张**：土耳其（视频）/ 印尼（量）作为第二、第三市场。
4. **每进一个新国**：先补齐"本地支付 + 本地语言审核 + 本地客服时区 + ASO 本地化"四件套再放量。

## 四、各区域"运营日历"关键节点（别错过营收窗口）

| 区域 | 关键节点 | 动作 |
|---|---|---|
| MENA | 斋月、开斋节、宰牲节、沙特国庆 | 提前 1-2 月备活动/主播/充值礼包，夜间档加重 |
| 欧美 | 圣诞、情人节、黑五 | 节日礼物皮肤、订阅促销 |
| 印度 | 排灯节(Diwali)、板球赛季 | 节日皮肤、低价充值包 |
| 东南亚 | 斋月(印尼/马来)、双 11/12 大促 | 钱包联合促销 |
| 拉美 | 狂欢节、世界杯/美洲杯 | 视频玩法、足球主题活动 |

## 五、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 一套素材/尺度投全球 | MENA 触红线被封、转化差 | 分区域素材+分区域审核尺度 |
| 把印度/非洲当收割场 | ARPPU 撑不起买量，亏损 | 印度非洲走规模+广告，海湾才收割 |
| 直接上最贵的海湾试错 | CPI 高，试错成本翻倍 | 先便宜市场验证再平移 |
| 错过斋月备战 | 错失全年最大营收窗口 | 提前 60 天排期备战 |
| 忽视本地支付，只接卡 | 新兴市场转化腰斩 | 必接本地钱包+运营商代扣 |
| 阿语只做翻译不做 RTL | 体验割裂、留存差 | 完整 RTL + 母语审校 |
| 土耳其和阿语区混为一谈 | 内容偏好错配 | 土耳其独立运营（偏视频） |

## 六、验收标准

- [ ] 主战场的本地支付、本地审核、本地客服、ASO 四件套就绪。
