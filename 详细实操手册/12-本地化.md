# 12 · 本地化（实操手册）

> 出海社交**最被低估的护城河**。赤子城的"后发优势"本质就是本地化更深。本篇给你**六层本地化清单 + 斋月运营手册 + RTL 落地**。

---

## 一、最佳实践

### 1.1 本地化是护城河，不是翻译 ✅
- 浅本地化（机翻+换语言包）会被本地化更深的对手碾压。

### 1.2 用本地人，不靠总部遥控 ✅
- 本地公会、本地红人、本地审核员、本地客服、本地运营 BD。

---

## 二、六层本地化清单

| 层次 | 浅（会被淘汰） | 深（能赢） |
|---|---|---|
| 语言 | 机翻 | 母语审校、口语俚语、**完整 RTL** |
| 文化 | 换语言包 | 节日运营（斋月）、本地审美、宗教禁忌规避 |
| 供给侧 | 远程招主播 | 本地公会/红人/审核员 |
| 支付 | 只接卡 | 本地钱包+运营商代扣 |
| 客服 | 英文邮件 | 本地语言+WhatsApp/本地 IM+本地时区 |
| 运营 | 总部遥控 | 本地运营/BD 团队懂当地玩法 |

---

## 三、斋月（Ramadan）运营手册（MENA 全年最大营收窗口）

> MENA 用户斋月**夜间活跃和消费暴增**，相当于 MENA 的"双 11"。错过=错过半年。

**提前 60 天排期：**
1. **内容**：斋月主题礼物皮肤（月亮/灯笼）、专属充值礼包、斋月活动玩法。
2. **供给**：提前签约/激励主播，保证斋月**夜间黄金档**有充足房间。
3. **运营**：斋月榜单、开斋时段专属活动、整月运营日历。
4. **买量**：斋月前预热拉新，斋月中加投承接高活跃高消费。
5. **客服**：夜间班次加强（用户作息整体后移）。

---

## 四、RTL（阿拉伯/希伯来语）落地
- 不只是文字方向：**布局镜像、图标方向、数字与时间格式、输入框对齐**全要适配。
- 用系统 API 的 `leading/trailing` 而非 `left/right`。
- 参考 Apple/Google 官方 RTL 指引；用阿语母语者实测。

## 六、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 机翻语言包 | 体验割裂、留存差 | 母语审校+口语化 |
| RTL 只翻文字不镜像布局 | 阿语用户体验破碎 | 完整 RTL 适配 |
| 错过斋月 | 错失全年最大窗口 | 提前 60 天排期 |
| 总部遥控无本地团队 | 不懂当地玩法、反应慢 | 本地运营/审核/客服 |
| 用错宗教/文化符号 | 触禁忌、被抵制 | 本地人审内容与素材 |
| 客服英文+总部时区 | 用户问题无人接 | 本地语言+本地时区客服 |

---

## 七、验收标准

- [ ] 主战场语言母语审校 + 完整 RTL（如适用）。
- [ ] 斋月等节点运营手册与日历就绪（提前 60 天）。
- [ ] 本地公会/红人/审核/客服/运营到位。
- [ ] 本地支付方式接入。
- [ ] 素材与内容经本地人审过文化禁忌。
