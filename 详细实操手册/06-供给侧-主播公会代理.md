# 06 · 供给侧 — 主播 / 公会 / 代理（实操手册）

> 这是整门生意**真正的护城河**。买量买来流量，供给侧决定留存和变现。本篇给你公会模型、分成结构、激励参数、PK 玩法、结算风控、召回 CRM 的全套落地方案。

---

## 一、最佳实践

### 1.1 礼物经济三方分账要透明 ✅
- 模型：用户买**钻石**→送礼物→主播收**豆子**→提现。BIGO 口径约 **210 豆 ≈ $1**。
- 三方分账：平台 + 公会（佣金 20-30%）+ 主播。**分账规则越透明，主播流失越低。**

### 1.2 "代理铺量 + 自营固本"双轨 ✅
- 代理网络快速冷启动供给；跑出来的头部主播**转平台直签**沉淀为自有壁垒。

### 1.3 多变现入口 ✅
- 抄 BIGO 的 **9 种变现**：虚拟礼物、PK 对战、官方签约、语音房、短视频、铁粉、邀请奖励、公会佣金、品牌赞助。

### 1.4 PK/排行榜/节点做成常态运营 ✅
- PK 是 ARPU 放大器（最后 10 秒礼物倍率引爆大额打赏）。

## 二、公会/代理体系实操

### 2.1 招募 SOP
1. **投放出量后代理会主动找上门**（脑图正确）——但要主动筛选，不是来者不拒。
2. 渠道：FB 群组、Google、本地社媒、行业群、线下 BD。
3. 准入：要求代理提供主播资源证明、缴纳**保证金**、签署分成与合规协议。

### 2.2 分级结构（脑图"层级无限制"需收敛）
- ⚠️ **建议层级 ≤ 2-3 级**：层级过深→主播到手过低→流失，且叠加结算与反洗钱风险。
- 设**主播分成下限保护**（如主播实得不低于流水的 X%），防止层层克扣。

### 2.3 激励设计（脑图"激励"细化）

| 激励项 | 参数示例（按区域调整） |
|---|---|
| 新人保护期 | 前 2-4 周底薪/保底，达标即给 |
| 时长任务 | 月开播 ≥ N 小时解锁奖励 |
| 流水阶梯 | 月流水档位越高分成越高 |
| PK/活动奖励 | 赢 PK、上榜额外奖 |
| 邀请奖励 | 拉新主播/用户返佣 |
- 🔧 **激励必须绑定归属关系并设上限**（脑图正确），否则被刷。BIGO 入门签约约 **$150-400/月**，头部 **$1,000-5,000+/月**。

### 2.4 PK 玩法落地
- 每周固定 PK 场次（头部主播 3-4 次/周维持曝光）。
- 最后 10 秒礼物倍率；阵营 PK 激发观众为"自己人"打赏。
- 配合周榜/月榜、守护/铁粉、限时礼包，形成"竞争-炫耀-打赏"永动机。

## 三、结算与风控（防代理克扣 — 这门生意的声誉地雷）

### 3.1 问题（脑图已点出）
> "会不会有代理克扣主播工资？主播有无申诉渠道？→会，但一般无法追回。"代理克扣/跑路会**批量流失主播、引发投诉甚至媒体曝光**。

### 3.2 系统性解决方案（五件套）
1. **平台直签头部主播**：优质主播平台直接结算，绕开代理克扣。
2. **结算透明化**：主播 App 内可见**流水明细、分成比例、到账记录**，消除信息差。
3. **分成下限 + 申诉通道**：设主播实得下限，提供站内申诉入口。
4. **代理保证金**：代理缴保证金，违规克扣从保证金扣罚。
5. **全链路审计留痕**：平台可回溯每一笔分账（脑图"代理后台可监查/追踪"升级为审计日志）。

### 3.3 提现通道（脑图正确，补合规提示）
- 主播提现：card→空中云汇 / epay / Payoneer 等。
- ⚠️ 提现链路涉及代收/拆分要做 **KYC/AML**，避免洗钱风险（见 09 合规篇）。

## 四、主播召回 CRM（脑图设计已很专业，给落地打法）

### 4.1 后台字段（脑图已列）✅
等级 / WhatsApp / 进来天数 / 生命周期 / 联系状态 —— 这是成熟主播 CRM。

### 4.2 按生命周期差异化召回

| 阶段 | 状态 | 召回策略 |
|---|---|---|
| 新主播(0-7天) | 未成势 | 一对一陪伴、开播指导、新人任务 |
| 成长期 | 有起色 | 流量扶持、PK 机会、阶梯激励 |
| 沉默期 | 开播下降 | 专属激励、活动召回、情感关怀 |
| 流失期 | 多日未开播 | 情感+利益双钩（专属返场礼包+老朋友话术） |

### 4.3 触达
- **WhatsApp/Telegram 自动化 + 本地语言客服**；按主播时区在其黄金开播前触达。

## 五、自营 vs 代理决策表

| 维度 | 代理/公会 | 平台自营 |
|---|---|---|
| 冷启动速度 | 快 | 慢 |
| 成本 | 轻（佣金） | 重（底薪+管理） |
| 可控性/质量 | 参差、有克扣风险 | 高、可控 |
| 壁垒 | 中（可被挖） | 高（直接关系） |
> 最佳：**代理铺量 + 头部转自营**。

## 六、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 代理层级过深 | 主播到手低、流失、AML 风险 | 层级≤2-3级+分成下限 |
| 代理克扣/跑路 | 主播流失、口碑崩 | 直签+透明结算+保证金+审计 |
| 激励不绑定归属/无上限 | 被刷、成本失控 | 绑归属+设上限 |
| 空有主播无玩法 | 开播没人送礼 | PK+榜单+铁粉常态化 |
| 只靠代理不沉淀 | 代理带走主播 | 头部转平台直签 |
| 召回一刀切 | 召回率低 | 按生命周期差异化 |
| 提现链路无 KYC | 洗钱/合规风险 | 提现 KYC/AML |

## 七、验收标准

- [ ] 分成结构透明、层级≤3级、有主播分成下限。
- [ ] 激励绑定归属并设上限，新人保护期就绪。
- [ ] PK+榜单+铁粉运营日历常态化。
- [ ] 结算可在主播端查明细、有申诉通道、代理有保证金、分账有审计。
- [ ] 召回 CRM 按生命周期分层 + 本地语言触达。
- [ ] 头部主播平台直签比例有目标。
