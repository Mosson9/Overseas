# 05 · 用户增长与买量（实操手册）

> 买量是油门不是发动机。本篇给你**渠道打法、归因配置、素材工厂 SOP、放量纪律、反作弊**全套可执行方案。

---

## 一、最佳实践

### 1.1 80% 效果由素材决定 ✅
- 定向只占小头，**素材是胜负手**。UGC 风格（真人出镜、本地语言、本地场景）跑赢精致广告片。

### 1.2 先有供给再开油门 ✅
- 买量前先把主播/房间/内容铺好。**空房买量=放血**（用户进来没人秒流失）。

### 1.3 按 D7 ROAS + 留存放量，而非看 CPI ✅
- 只在"D7 ROAS 趋势健康 + 留存达标"的**渠道×国家×素材**组合上加预算。

### 1.4 归因与反作弊先于花钱 ✅
- 没有 MMP 就是盲投；新兴市场 20-40% 预算可能喂给假量。

## 三、实操指南

### 3.1 归因(MMP)配置 SOP
1. 选 MMP：AppsFlyer / Adjust / Singular。
2. 接入各渠道回传（SKAdNetwork/隐私聚合 + 自归因）。
3. 定义关键事件：注册、首次互动、首充、复充、订阅。
4. 打开**反作弊模块**（如 AppsFlyer Protect360）。
5. 建分国家/渠道/素材的 ROAS 看板。

### 3.2 素材工厂 SOP（把买量工业化）
- **产能**：每周产出几十条变体（钩子×开头 3 秒×号召语 矩阵组合）。
- **本地化**：阿语口播+本地面孔；印尼用本地网红；禁止一套英文打全球。
- **钩子模板（被验证高 CTR）**：1v1 偶遇感、语聊房热闹感、"附近的人在线"、礼物/排行榜炫耀感、女主播打招呼感（⚠️ 注意素材合规尺度）。
- **测试法**：小预算并行测多条 → 杀掉低 CTR/高 CPI → 放大胜出素材 → 持续迭代衰退素材。

### 3.3 放量纪律（决定盈亏）
- 新组合先用**小预算探**（看 D0-D3 信号）。
- 达标信号（示例基准，按品类调整）：次留 > 30-40%、注册成本达标、**D7 ROAS 趋势向回本线收敛**。
- 达标才**阶梯加预算**（每次 +20-30%，避免学习期重置）；不达标快速关停。

### 3.4 广告账户矩阵（抗封）
- FB/Google 对"性暗示/诱导/夸大交友"素材封户极快。
- 准备**BM/广告户矩阵 + 合规素材版**，主推合规版，激进版隔离测试，户被封不影响大盘。

## 四、竞品投放研究法（脑图方法升级）

1. **看榜**：Sensor Tower / data.ai / 点点数据，目标国社交畅销榜挑 5-10 个对标。
2. **看收入**：免费看当月，付费/交叉验证看历史趋势，锁定 ARPPU 高的。
3. **反查素材**：**AppGrowing（国际版）** 看对标在投素材与渠道；**Meta Ad Library** 免费看 FB/IG 在投。
4. **拆钩子**：把对标素材的"开头 3 秒钩子 + 卖点 + 号召语"拆出来，复刻并 A/B。
5. **回算**：用自己 MMP 数据回算 ROAS，决定加减预算。

## 六、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 没装 MMP 盲投 | 不知钱花哪、无法优化 | 先配 MMP 再花钱 |
| 假量刷量 | 20-40% 预算打水漂 | 开反作弊、用真实本地渠道 |
| 空房买量 | 用户秒流失、ROAS 崩 | 先铺供给再放量 |
| 看 CPI 放量 | CPI 低但留存/付费差 | 按 D7 ROAS+留存放量 |
| 一套英文素材打全球 | CTR/CVR 低 | 本地化 UGC 素材 |
| 激进素材封广告户 | 投放中断 | 广告户矩阵+合规素材版 |
| KOL 按曝光付费无追踪 | 钱花了没转化 | 专属码+效果结算 |
| 加预算太猛重置学习期 | 成本飙升 | 阶梯式 +20-30% |
