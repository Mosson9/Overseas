# 04 · 商店审核与 ASO（实操手册）

> 过审是 0 到 1，ASO 是 1 到 N 的免费流量放大器。本篇给你**过审 SOP、4.3 规避清单、被拒应对话术、ASO 本地化打法**。

---

## 一、最佳实践

### 1.1 过审的本质是"看起来像个独立、完整、合规的产品"✅
- App Store **Guideline 4.3 Spam 占全部拒审约 28%**，是头号拒审理由。它打击重复功能/代码/素材、模板批量、跨号相似 App。
- 过审三要素：**功能完整可用、内容合规、与他人/自己其他 App 有实质差异**。

### 1.2 合规差异化，而非欺骗审核 ✅
- 用创意玩法、本地化、社交关系链做真差异。
- ⚠️ **绝不做"壳过审后切直播/1v1"的审核欺骗**：被抓=直接终止开发者账号+连坐关联号，是这门生意最贵的错误。

### 1.3 UGC 政策硬要求必须内置 ✅
- 实时音视频/UGC 产品上线即需具备：**举报、屏蔽、内容审核、未成年人保护、用户协议中的 0 容忍条款（EULA against objectionable content）**。Apple 1.2 / Google UGC 政策都查这个。

## 二、实操指南：过审 SOP

### 2.1 提交前自查清单（iOS）

| 检查项 | 说明 |
|---|---|
| 功能完整 | 无白屏、无占位、无"敬请期待"、登录可用 |
| 4.3 差异化 | UI/功能/文案/玩法 > 50% 差异；不复用他人模板指纹 |
| UGC 合规 | 举报+屏蔽+审核+0 容忍 EULA+联系方式 |
| 未成年人 | 年龄分级正确、年龄门、青少年保护 |
| 1.2 实时 | 实时音视频需有内容审核与封禁机制说明 |
| 支付合规 | 数字内容走 IAP，无 App 内跳转外部支付 |
| 隐私 | 隐私政策链接有效、App 隐私清单(Privacy Nutrition Label)如实填写、ATT 弹窗 |
| 演示账号 | 提供可用测试账号、必要时录屏演示 |
| 元数据 | 截图与实际功能一致、无违规词、无竞品名 |

### 2.2 国家错峰发布（避 4.3 的官方合规招）
- App Store「国家/地区可用性」先选 **None**，再勾选目标国，使相似 App 之间**国家不重叠**。这是 Apple 官方建议的降重复判定做法。

### 2.3 审核加速与沟通
- 用 **App Review** 备注栏写清产品定位、测试账号、合规机制。
- 重大版本可申请 **Expedited Review**（慎用，别滥用）。

## 三、被拒应对：分条款话术

| 拒审条款 | 含义 | 应对 |
|---|---|---|
| **4.3 Spam** | 判你重复/模板 | 强调差异点、调整国家不重叠、必要时重构 UI/功能后重提，Resolution Center 礼貌说明独立性 |
| **1.2 UGC** | 缺审核/举报机制 | 补齐举报+屏蔽+审核+EULA，录屏演示 |
| **2.1 完整性** | 功能不全/崩溃 | 修复后重提，提供演示账号 |
| **3.1.1 支付** | 绕过 IAP | 改为 IAP，移除 App 内外部支付入口 |
| **5.x 法律** | 内容违法/隐私 | 按地区合规整改 |

> Resolution Center 沟通原则：**礼貌、对事、提供证据、不狡辩、不情绪化**。多数 4.3 可通过差异化+错峰国家+重提解决。

## 四、ASO 本地化实操

### 4.1 关键词（按国家做，不是翻译）
- 阿语/印尼语/土耳其语用**本地母语者审过的口语化关键词**，不要机器翻译堆词。
- 工具：App Store Connect 搜索热度、第三方 ASO 工具（如 AppTweak/Mobile Action）、本地人验证。

### 4.2 转化三件套（决定 CVR）
- **图标**：本地审美（MENA 偏华丽、人物着装保守）。
- **前 3 张截图**：讲清"热闹/在线/有人陪"的核心钩子，按国家分别制作。
- **首条评论与评分**：合规引导真实用户在前期拿到 **4.5+**，对自然量与买量 CVR 双重放大。

### 4.3 冷启动评分（合规做法）
- App 内在用户"爽点时刻"（如收到礼物、匹配成功）触发系统评分弹窗（`SKStoreReviewController`）。
- ⚠️ 不买评、不诱导五星（违规且触发关联风险）。

## 五、非 GMS 与多渠道（脑图已列，落地补充）
- 印度/东南亚/非洲大量机型缺 GMS：**华为 AppGallery、小米 GetApps、三星 Galaxy Store、Transsion（TECNO/Infinix/itel）预装**是重要增量。
- 各商店有各自审核与本地化要求，单独建包与素材。

## 六、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 模板换皮、共享后端/截图 | 4.3 团灭 | 实质差异化+国家错峰+独立资产 |
| 壳过审后切高风险形态 | 终止账号+连坐 | 不做审核欺骗 |
| UGC 没有举报/审核机制 | 1.2/UGC 拒审 | 上线即内置全套合规机制 |
| 元数据含竞品名/违规词 | 拒审 | 元数据合规自查 |
| 机翻关键词堆砌 | 搜索权重低、转化差 | 本地母语关键词 |
| 全球一套截图 | CVR 低 | 按国家做图标与前 3 张图 |
| 买评提分 | 触发关联/政策违规 | 系统弹窗合规引导 |

## 七、验收标准

- [ ] iOS/Android 提交前自查清单全过。
- [ ] 相似 App 国家不重叠配置完成。
- [ ] UGC 合规机制（举报/屏蔽/审核/EULA/未成年人）已内置并可演示。
- [ ] 主战场 ASO 三件套（图标/前 3 图/关键词）本地化完成。
- [ ] 合规冷启动评分机制上线。
