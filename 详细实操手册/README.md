## 怎么用这套手册

1. **先读全景指南** 建立全局认知与决策框架。
2. **按当前阶段挑模块**：
   - 还没定方向 → 01、02
   - 准备上线 → 03、04、07、09、10
   - 冷启动期 → 06、05、15
   - 增长爬坡 → 05、08、14
   - 全程贯穿 → 07（内容安全）、09/10（合规）、11（技术）、12（本地化）
3. **每个模块跟着"验收标准"打钩**，确认真正落地而非只读。

## 全局优先级提醒

> 在所有模块里，有三条是**决定生死、不能省**的：
> 1. **内容安全与审核（07）** — 一次大事故团灭整个矩阵。
> 2. **账号隔离与封号应急（03）** — 主体关联是头号杀手。
> 3. **资金合规回款（09）** — 灰色回款是老板进局子的最高频原因。
>
> 其余模块决定你跑多快，这三条决定你能不能活着跑。
