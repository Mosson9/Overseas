# 专项细案 · Phase 1 前 21 天逐日执行清单（MENA 语聊房）

> 这是《[90 天作战计划](../../90天作战计划-MENA语聊房.md)》**Phase 1 地基期**的逐日展开——把"做地基"拆成每天谁干什么、产出什么、卡哪个依赖。

## 附录 A · 海湾公会 BD 招募话术（首轮触达）

> 渠道:投放出量后代理会主动找上门(被动) + 主动出击(行业群、社媒、线下、老 BD 转介绍)。语言:英语/阿拉伯语。

**首轮触达(简短价值主张,30 秒讲清):**
> "我们是新上线的语音社交平台,主打海湾市场。给公会的条件:**有竞争力的分成 + 新人房主保护期激励 + 透明可查的结算(主播 App 内看明细)+ PK/榜单流量扶持**。正在招募首批种子公会,名额有限,想了解可以约个详谈。"

**钩子(选用):**
- 分成有竞争力 + 结算透明(主播能 App 内看明细,杜绝克扣纠纷)。
- 平台直接的流量扶持(PK 赛事、榜单曝光)。
- 首批种子公会有额外政策/赛事资源(稀缺性)。

## 附录 B · 公会首谈 SOP（约 30-45 分钟）

1. **了解对方(听 60%)**:现有主播数/活跃数、所在国、过往合作平台、为什么想换/加平台。
2. **介绍平台(讲 30%)**:形态、海湾定位、分成与激励、流量扶持、结算透明机制。
3. **谈合作框架**:分成比例(附录 C 框架)、保证金、铺房承诺、新人保护期、试运营周期。
4. **亮合规底线**:不接受刷量/虚假流水、不接受擦边违规内容、不接受克扣主播(平台可审计、主播可申诉)。
5. **约定下一步**:试运营房间数、首周目标、签约时间表。

## 附录 C · 公会尽调清单（签约前必查）

| 项 | 查什么 | 红线 |
|---|---|---|
| 主播资源真实性 | 要样例主播、过往开播数据 | 资源造假 |
| 过往平台口碑 | 是否有克扣/跑路黑历史 | 有克扣前科 |
| 结算合规 | 提现是否走合规通道、能否配合 KYC | 拒绝 KYC |
| 内容倾向 | 是否依赖擦边引流 | 擦边为主 |
| 刷量历史 | 是否有自充自刷套激励记录 | 刷量套利 |

> 配合《[代理结算与分成协议模板](代理结算与分成协议模板.md)》签约,协议须经律师本地化定稿。
