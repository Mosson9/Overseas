# 专项细案 · 海湾变现配置：充值档位、礼物定价与埋点清单

> 把 08《变现》落成**可直接配置的表**:钻石/豆子体系、海湾本地化充值档位、礼物定价、荣誉体系,以及给研发/数据的**埋点字段清单**。
> ⚠️ 所有金额为**指示性**,须按竞品(Yalla/YoHo)与本地消费力校准;货币以 **SAR(沙特里亚尔)/AED(迪拉姆)/USD** 标注。

---

## 一、货币体系

| 货币 | 用途 | 说明 |
|---|---|---|
| **钻石(充值币)** | 用户充值购买 | **仅 App 内购(IAP)**,绕过=下架(见 09 篇) |
| **豆子(结算币)** | 主播收礼获得、可提现 | 经平台+公会分账(见 06 篇) |
| 兑换比 | 钻石→礼物→豆子 | 参考 BIGO 约 210 豆≈$1,按抽成设计 |

> 设计原则:充值币与结算币**分离**,平台通过"礼物面值 vs 豆子兑现率"控制抽成与成本。

## 二、充值档位设计表（海湾本地化,指示性）

| 档位 | 价格(示意) | 钻石 | 赠送 | 目的 |
|---|---|---|---|---|
| 首充特惠 | ~3.99 SAR / 0.99 USD | 基础 | **超高赠送(限一次)** | 击穿首付费门槛 |
| 入门档 | ~19 SAR / 4.99 USD | … | 小赠送 | 高频小额 |
| 主力档 | ~75 SAR / 19.99 USD | … | 中赠送 | 对齐当地常见消费 |
| 进阶档 | ~199 SAR / 49.99 USD | … | 高赠送 | 中 R |
| 大额档 | ~399+ SAR / 99.99+ USD | … | 最高赠送+专属礼物 | 大 R 鲸鱼 |
| 限时礼包 | 节点(斋月)专属 | … | 节日加赠 | 节点爆发 |

🔧 **要点**:
- 价格**按当地货币设"心理价位"**,不要美元直接换算成零头。
- **首充礼包**单独突出、限一次、超值——首付费转化的核心杠杆。
- 大额档配**专属礼物/座驾/标识**,给大 R 炫耀资本。

## 三、礼物体系定价表（分价格带）

| 价格带 | 例子 | 作用 |
|---|---|---|
| 小额高频 | 玫瑰、点赞、小爱心 | 低门槛互动、暖场 |
| 中额 | 花束、皇冠、蛋糕 | 日常表达、PK 助力 |
| 大额炫耀 | 跑车、游艇、城堡(全屏特效) | 冲榜、全场可见、大 R 主战场 |
| 座驾/入场特效 | 豪车入场、专属音效 | 身份炫耀(进房全场看到) |
| 限定/节点 | 斋月月亮、节日限定 | 稀缺性、节点爆发 |

🔧 礼物→**主播收益与榜单即时可见**,形成"送礼-回应-再送礼"正循环(见 08 篇)。

## 四、荣誉与等级体系（非现金驱动力,MENA 关键）

| 体系 | 设计 |
|---|---|
| 用户财富等级 | 累计充值/消费升级,等级标识 |
| 主播魅力等级 | 累计收礼升级 |
| 榜单 | 财富榜/魅力榜/公会榜(日/周/月) |
| 守护/铁粉 | 用户绑定主播,专属标识与特权 |
| 贵宾/VIP | 隐身、专属座驾、贵宾房、专属客服 |

## 五、大 R 分层与权益

| 层级 | 划分(示意,按累计充值) | 权益 |
|---|---|---|
| 普通 | — | 基础 |
| 中 R | 月充 ≥ 阈值 | 专属礼物、等级加速 |
| 大 R | 月充 ≥ 高阈值 | VIP 经理、贵宾房、专属座驾 |
| 超 R(鲸鱼) | Top 充值 | 一对一关怀、定制权益、线下关系维护 |

🔧 大额充值**人工风控复核**防盗刷拒付;大 R 充值/活跃骤降触发**专属召回**(见 08/09 篇)。

## 六、埋点字段清单（给研发/数据,北极星与漏斗的基础）

> 每个事件至少带:`user_id, country, device, channel(归因), session_id, timestamp`。下表列**事件特有字段**。

| 事件 | 特有字段 | 用途 |
|---|---|---|
| register | reg_method, is_new | 注册漏斗 |
| login | — | 活跃 |
| enter_room | room_id, room_type, room_owner_id | 进房率/房间分布 |
| take_mic | room_id, seat_no | **首日有效互动** |
| send_message | room_id, msg_type | 互动深度 |
| send_gift | room_id, receiver_id, gift_id, **gift_value**, combo | 变现核心 |
| receive_gift | sender_id, gift_id, gift_value | 主播收益 |
| recharge | **package_id, amount, currency, pay_method, is_first** | 付费漏斗/首充 |
| recharge_result | status, fail_reason | **充值失败→客服入口触发** |
| follow / guard | target_id, type | 关系链/守护 |
| rank_view / rank_up | rank_type, rank_pos | 榜单驱动 |
| share | channel, content_type | 传播 |
| report | target_id, reason | 内容安全闭环 |
| ad_impression / reward_ad | placement | 广告变现(低 ARPU 区) |

## 七、漏斗与北极星映射

```
install → register → enter_room → take_mic/send_message(首日有效互动)
   → send_gift(首次送礼) → recharge(首充) → 复充 → 大 R
```
- **北极星**:付费用户有效互动时长 / D7 留存的付费用户数(见 14 篇)。
- 每环转化做看板,定位最大流失断点优先优化。

## 八、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 美元直接换算定价 | 心理价位别扭、转化差 | 本地货币心理价位 |
| 无首充礼包 | 首付费转化低 | 限一次超值首充 |
| 礼物只有现金属性 | 打赏动力不足 | 荣誉/榜单/座驾炫耀 |
| 埋点缺字段 | 漏斗算不出、无法下钻 | 按本清单埋全,带归因字段 |
| 充值失败无事件 | 用户跑去商店投诉 | recharge_result 触发客服入口(见 13 篇) |
| 大额充值无风控 | 盗刷拒付 | 人工复核+风控(见 09 篇) |
| 无大 R 分层 | 鲸鱼流失即腰斩 | 分层权益+流失预警 |

## 九、验收标准

- [ ] 钻石/豆子体系与兑换比/抽成设计确定。
- [ ] 充值档位本地化(SAR/AED 心理价位)+ 首充/限时礼包上线。
- [ ] 礼物分价格带 + 座驾入场特效 + 节点限定。
- [ ] 荣誉/等级/榜单/守护/贵宾体系就位。
- [ ] 大 R 分层权益 + 流失预警 + 大额风控。
- [ ] 埋点按清单全量上报、带归因字段,漏斗看板可用。
- [ ] 充值失败事件联动客服入口。
