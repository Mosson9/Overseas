# 专项细案 · 阿语 UGC 买量素材脚本库（MENA 语聊房）

> "80% 的买量效果由素材决定"(见 05 篇)。本篇给你**可直接拍的钩子脚本库 + 规格 + 合规红线 + A/B 维度 + 迭代 SOP**,喂给素材工厂用。
> ⚠️ 所有阿语口播/字幕**必须本地母语者审校**;本文给场景与结构,文案以本地化定稿为准。

---

## 一、铁律（先记住这几条）

1. **前 3 秒定生死**:开场就要有"热闹/有人/冲突/好奇"钩子,慢热=划走。
2. **真人 UGC > 精致广告片**:本地面孔、手机竖屏、像朋友分享。
3. **本地化到骨子里**:阿语口播、海湾场景、本地服饰审美(保守)、本地音乐。
4. **一条素材一个钩子**:别堆功能,讲清一个情绪点。
5. **合规优先**:不性暗示、不夸大交友承诺、不诱导——否则封广告户+触平台红线(见第五节)。

## 三、可拍脚本（每条:场景 / 开场 3 秒 / 中段 / CTA）

### 脚本 1 · H1 热闹交友房（15s,竖屏）
- **场景**:本地年轻人拿手机,背景是热闹的语音房 UI(多人头像+麦上波纹)。
- **开场 3 秒**:画面直接给"满麦的房间 + 弹幕刷礼物",口播:「这里现在好多人在聊!」
- **中段**:快速展示进房→上麦→和陌生人聊起来→收到一个礼物特效。
- **CTA**:「快来加入,免费上麦聊天」(阿语本地化)。

### 脚本 2 · H2 语音偶遇（15s）
- **场景**:一个人无聊刷手机的表情。
- **开场 3 秒**:「无聊?进来随便聊两句」+ 一进房就匹配到一个聊得来的人。
- **中段**:两人语音对话的轻松氛围(字幕呈现对话),笑出来。
- **CTA**:「现在就有人在线,点开就聊」。

### 脚本 3 · H4 送礼上榜炫耀（20s,偏变现/大 R）
- **场景**:房间里有人刷大礼物,全场特效炸开,送礼人名字上财富榜首。
- **开场 3 秒**:一个豪华礼物特效铺满屏 + 「全场都在看他」。
- **中段**:展示榜单、座驾入场、贵宾标识带来的"被注目"。
- **CTA**:「上榜被全场看见,就在 XX」。

### 脚本 4 · H6 深夜情感陪伴（15s,夜间投放）
- **场景**:夜晚,城市灯光,一个人戴耳机靠在窗边。
- **开场 3 秒**:「睡不着的夜晚,有人陪你聊到天亮」。
- **中段**:温暖的语音房氛围,轻声聊天。
- **CTA**:「深夜不孤单,进来聊聊」。

### 脚本 5 · H7 Ludo + 语音开黑（20s,游戏房）
- **场景**:朋友们边玩 Ludo 边语音。
- **开场 3 秒**:「Ludo 还能这么玩?边玩边语音!」掷骰子+欢呼。
- **中段**:输赢时的语音互动、笑闹。
- **CTA**:「叫上朋友,边玩边聊」。

### 脚本 6 · H8 斋月夜聊（15s,斋月节点)
- **场景**:斋月夜晚、灯笼氛围、开斋后家人朋友聚。
- **开场 3 秒**:「斋月夜,大家都在这里聊」+ 斋月主题房间皮肤。
- **中段**:斋月专属礼物、祝福、热闹房间。
- **CTA**:「斋月快乐,进来一起」。

> 每条都做 **3-5 个开场 3 秒变体**(不同钩子句/不同首帧),这是 A/B 的主战场。

## 四、素材规格（交付标准）

| 项 | 标准 |
|---|---|
| 比例 | 竖屏 9:16(适配 FB/IG/TikTok/Snap) |
| 时长 | 9-20 秒为主,测 6 秒短版 |
| 字幕 | 阿语字幕(母语审校),静音可看懂 |
| 出镜 | 本地面孔、本地服饰(保守)、本地场景 |
| 音乐 | 本地流行/斋月氛围,版权合规 |
| 品牌 | 露出 App 名/图标,但前 3 秒先给钩子 |
| 数量 | 每周几十条变体(钩子×开场×CTA×时长) |

## 五、合规红线（投放素材,违反=封户+平台风险）

- ❌ 性暗示、暴露、诱导性肢体语言。
- ❌ 夸大承诺("保证找到对象/约会")。
- ❌ 虚假 UI(展示产品没有的功能)。
- ❌ 诱导误点、虚假按钮。
- ✅ 真实房间体验、真实玩法、情绪共鸣。
- 🔧 激进版素材**与广告户矩阵隔离测试**,主推合规版,户被封不伤大盘(见 05 篇)。

## 六、A/B 测试维度与命名

**测试维度**:钩子类型(H1-H8)× 开场 3 秒 × CTA 文案 × 时长 × 音乐 × 出镜人。
**命名规范**(便于归因):`国家_钩子_开场版本_CTA版本_时长_日期`,如 `SA_H1_v3_cta2_15s_0712`。
**迭代 SOP**:小预算并行测 → 杀低 CTR/高 CPI → 放大胜出 → 持续出新替衰退(素材会疲劳)。

## 七、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 一套英文素材打全球 | CTR/CVR 低 | 阿语本地化 UGC |
| 开场慢热 | 前 3 秒划走 | 钩子前置 |
| 精致广告片 | 不如 UGC 真实感 | 真人手机竖屏风格 |
| 素材不更新 | 疲劳、CPI 涨 | 持续出新替衰退 |
| 阿语机翻字幕 | 别扭、不信任 | 母语审校 |
| 擦边博 CTR | 封户+平台红线 | 合规版主推、隔离测激进版 |
| 无命名规范 | 无法归因哪条赢 | 统一命名+MMP 对齐 |
