# 专项细案 · 斋月（Ramadan）作战手册

> 斋月是 MENA 社交产品**全年最大的营收窗口**——夜间活跃与打赏消费暴增，相当于 MENA 的"双 11+春节"。错过 = 错过半年业绩。
> 本手册给你一份 **T-60 倒计时排期表 + 六条工作流详案 + KPI + 复盘模板**，照着执行即可。

---

## 一、为什么斋月值得你 All-in

- 斋月期间穆斯林用户**白天斋戒、夜间社交娱乐消费集中爆发**，语音房/直播的夜间时长与礼物流水大幅抬升。
- 送礼/炫耀文化 + 节日氛围 + 家庭团聚夜聊 → 打赏意愿最高的一段时间。
- 头部产品（Yalla、MICO/YoHo、BIGO）都把斋月当作年度战役级运营节点。

### 斋月时间（重要：每年提前约 11 天，须以月相为准）
- **下一个斋月：约 2027-02-08 前后开始，开斋节(Eid al-Fitr)约 2027-03-10 前后**（具体日期以各国官方月相宣告为准，可能±1-2 天）。
- 因此本手册的 **T-60（启动）≈ 2026 年 12 月初**。
- ⚠️ 不同国家开始日可能差 1 天，UAE/沙特通常同步，需分国家确认。

## 二、斋月内的用户作息（决定你的运营节奏）

| 时段 | 用户状态 | 你的动作 |
|---|---|---|
| Suhoor（黎明封斋前，凌晨~黎明） | 起床进食、轻活跃 | 小高峰，安排早场房间/轻活动 |
| 白天（斋戒中） | 活跃最低 | 低谷，做内容储备、维护、客服 |
| Iftar（日落开斋，傍晚） | 开斋聚餐、活跃回升 | 开斋专属活动、礼包推送 |
| **夜间（开斋后~深夜）** | **活跃与消费最高峰** | **主力战场：主播全员上、PK/榜单/大额礼包全开** |
| 深夜~凌晨 | 持续高活跃 | 延长黄金档，保证有房 |

> **核心结论：把资源（主播排班、活动、买量承接、客服）全部向"夜间黄金档"倾斜。**

## 四、六条工作流详案

### 工作流 1：内容与活动（T-45 起开发）
- **斋月主题皮肤**：礼物（月亮/灯笼/椰枣/清真寺剪影）、房间装扮、入场特效、头像框。
- **专属活动**：斋月榜单（财富榜/魅力榜/公会榜）、每日 Iftar 开斋签到、整月累充返利、斋月任务体系。
- **节奏**：每周一个主题小活动 + 整月一条大主线（如"斋月之星"主播赛）。
- 开斋节(Eid)单独设**高潮大促**（最大力度礼包、压轴活动）。

### 工作流 2：供给侧（主播/公会，T-45 起锁定）
- 提前与公会签**斋月专项激励**：夜间黄金档开播奖励、流水阶梯、PK 赛事奖金。
- 保证**夜间黄金档房间覆盖充足**（按时区与各国排班，别出现空房）。
- 头部主播提前预热，绑定斋月赛事 IP。
- 储备替补主播，防止旺季掉线。

### 工作流 3：买量与承接（T-21 预热，斋月中加投）
- T-21 起**预热拉新**，把新用户养到斋月正好活跃。
- 斋月中**加大投放承接高活跃高消费**（此时 ROAS 通常更好，可提预算）。
- 素材换斋月版（节日祝福、热闹夜聊、开斋氛围），分国家本地化。
- ⚠️ 投放节奏匹配作息：**夜间黄金档加投**。

### 工作流 4：用户运营与召回（T-21 起）
- 召回流失用户："斋月快乐 + 专属返场礼包"（WhatsApp/推送/私域）。
- 大 R 专属斋月关怀（专属经理、专属礼物、定制祝福）。
- 新用户首充斋月礼包，老用户累充返利。

### 工作流 5：客服与风控（全程，夜间加强）
- **夜间班次加强**（用户作息后移，问题集中在夜间）。
- 充值失败/到账问题**快速响应**，拦在用户去商店投诉之前（见 13 产品细节篇）。
- **风控升级**：旺季是盗刷/拒付/刷量高发期，加强大额充值审核（见 09 支付篇）。
- 内容审核夜间加强（高活跃=高违规风险，见 07 审核篇）。

### 工作流 6：稳定性与技术（T-21 压测）
- 对**夜间峰值**做容量压测与扩容预案（RTC 并发、支付、推送）。
- 监控告警就位，关键路径（进房/送礼/充值）SLA 保障。

## 五、KPI（斋月战役看板）

| 维度 | 指标 |
|---|---|
| 规模 | 斋月 DAU/MAU 增幅、新增、召回回流 |
| 时长 | 夜间黄金档人均时长、房间数/开播主播数 |
| 变现 | 斋月总流水、付费率、ARPPU、大 R 充值、首充转化 |
| 买量 | 斋月期 ROAS、新增成本、承接效率 |
| 供给 | 黄金档房间覆盖率、主播开播率/留存 |
| 健康 | 拒付率、违规拦截量、客服时效、系统可用性 |

## 六、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| T-30 才启动 | 内容/主播/素材来不及 | T-60 启动，排期冻结 |
| 资源平均分配全天 | 错失夜间黄金档 | 资源向夜间倾斜 |
| 主播供给不足 | 旺季空房、流量浪费 | T-45 锁定主播+替补储备 |
| 旺季不加风控 | 盗刷拒付暴增 | 大额审核+风控升级 |
| 客服白班配置 | 夜间问题无人接、商店差评 | 夜间班加强 |
| 未压测峰值 | 高峰宕机、口碑崩 | T-21 压测+扩容预案 |
| 各国按同一天 | 开始/开斋日差错 | 分国家确认月相日期 |
| 忽视开斋节(Eid) | 错过压轴高潮 | Eid 单设最大力度大促 |
