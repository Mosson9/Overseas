# 专项细案 · 阿语内容审核外包：对接与考核标准

> 内容安全是 MENA 语聊房的**生死线**(见 07 篇)。机审兜底 + **本地阿语人审**是标配。本篇给你**外包选型、对接 SOP、考核指标、质检机制**,把"找个外包团队"变成"可管理、可考核、可问责"的体系。

---

## 一、为什么是"机审兜底 + 阿语人审外包"

- 机审解决**规模与秒级拦截**,但对阿语方言、宗教/政治语境、擦边语音的判断力不足。
- 海湾尺度全球最严(宗教/政治/两性是法律级红线),**必须有懂本地语言文化的人审**。
- 自建阿语审核团队成本高、起步慢;**外包 + 平台自管标准与质检**是务实起步方式。
- ⚠️ 外包不等于甩手:**标准、手册、考核、质检、最终处置权必须握在自己手里**。

---

## 二、外包选型与 SOW（合同要点）

| 维度 | 要求 |
|---|---|
| 语种/方言 | 阿语(海湾方言为主)+英语;最好覆盖埃及方言(铺量市场) |
| 覆盖时间 | **7×24**,重点保障海湾夜间黄金档(高活跃=高风险) |
| 时区 | 排班对齐海湾时区,夜间加强 |
| SLA 响应 | P0(高危)**分钟级**、P1 **≤4 小时**、P2 抽样;明确响应与处置时效 |
| 计费 | 按席位/按工时/按审核量,明确加班与峰值(斋月)弹性 |
| 保密与数据 | NDA + 数据访问最小化 + 不得外泄录像/截图(见第六节) |
| 工具权限 | 用你的审核后台,分级权限,操作留痕 |
| 验收与退出 | 试用期考核、不达标更换条款 |

---

## 三、对接 SOP（上线前必做）

1. **审核知识库交付**:把审核标准做成**图文审核手册**——分级标准(P0/P1/P2)、各国红线、正反例图文、阿语敏感语境示例。
2. **分级处置 SOP 培训**:对照 07 篇 P0/P1/P2,明确每级"机器动作+人工动作+时效"。
3. **工具与权限**:开审核后台账号、分级权限、操作日志;明确**留证(录像/截图)**链路。
4. **试审校准**:用历史/构造样本做**试审**,与平台标准对齐(消除尺度偏差)。
5. **升级通道**:疑难/边界 case 的上报与平台终裁机制。
6. **正式上线**:小流量灰度 → 全量,前两周高频质检。

---

## 四、考核标准（KPI,把外包变得可问责）

| 指标 | 定义 | 目标(指示性) |
|---|---|---|
| **准确率** | 判定正确数 / 总判定数 | ≥ 98% |
| **漏判率(最关键)** | 漏放的违规 / 实际违规 | **趋近 0**(P0 漏判零容忍) |
| 误判率 | 错误处罚的正常内容 / 总处罚 | ≤ 设定阈值(避免误伤体验) |
| P0 响应时效 | 高危从触发到处置 | 分钟级 |
| P1 响应时效 | 中危处置 | ≤ 4 小时 |
| 举报处置时效 | 用户举报到反馈 | ≤ 设定 SLA |
| 质检通过率 | 平台抽检合格率 | ≥ 95% |

> **漏判(尤其 P0:露点/涉政/未成年人)是一票否决项**——一次大漏判可能整号团灭,比误判严重得多。考核权重向"零漏判"倾斜。

---

## 五、质检与抽审机制（平台自管的核心）

1. **平台侧质检员**(可 1 人起)每日**随机抽审**外包处置结果(如抽 1-5%)。
2. **双盲复核**:对 P0/争议 case 平台独立复核,比对外包判定。
3. **周质检报告**:准确率/漏判/误判/时效,按审核员个体出分。
4. **奖惩挂钩**:质检结果与外包结算/续约挂钩;个体审核员红线漏判直接换人。
5. **持续校准**:每周用新出现的违规样本更新词库/手册/培训(违规手段在进化)。

---

## 六、数据安全与合规（别让审核成为新风险源）

- 录像/截图/用户数据**最小化访问**,审核后台水印+操作留痕,防外泄。
- 外包人员签 NDA;离职即收回权限。
- 留证数据按合规要求存储(与 10 篇数据本地化呼应),仅用于审核与申诉举证。

---

## 七、与机审/产品的协同

- 机审**秒级拦截 P0**(不等人审),人审复核+处理 P1/疑难+申诉。
- 高危直播**先切断再人审**,宁可误伤一秒也不放过 P0。
- 审核结果回流**训练机审模型**,降人审压力(机审越用越准)。

---

## 八、常见的坑 + 解决方案

| 坑 | 后果 | 解决方案 |
|---|---|---|
| 甩手给外包不自管标准 | 尺度失控、漏判团灭 | 标准/手册/质检/终裁握自己手里 |
| 只考核准确率不盯漏判 | P0 漏判酿大事故 | 漏判零容忍、权重倾斜 |
| 白班排班 | 夜间黄金档高危漏审 | 7×24、夜间加强 |
| 审核员不懂海湾方言/语境 | 阿语违规漏判 | 选海湾方言能力、试审校准 |
| 无质检抽审 | 外包质量不可控 | 平台日抽审+周报告+奖惩 |
| 词库手册不更新 | 新违规手段漏网 | 每周校准更新 |
| 留证数据无管控 | 数据外泄/合规风险 | 最小访问+水印+留痕+NDA |

## 九、验收标准

- [ ] 外包 SOW 明确语种/方言、7×24、SLA、保密、退出条款。
- [ ] 审核手册(分级+红线+正反例)交付并完成试审校准。
- [ ] 机审秒级拦截 P0 + 人审复核链路打通,留证可用。
- [ ] 考核 KPI(准确率/漏判/时效/质检)定义并上线,漏判零容忍。
- [ ] 平台侧质检员日抽审 + 周质检报告 + 奖惩挂钩运转。
- [ ] 留证数据安全管控(最小访问/水印/留痕/NDA)就位。
- [ ] 每周词库/手册校准机制运行。
